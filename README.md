# Python Voice Assistant

A Python-based voice assistant that uses speech recognition and text-to-speech to perform common desktop tasks through voice commands.

## Features

- 🎤 Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open websites such as YouTube, Google, GitHub and LinkedIn
- 📚 Search Wikipedia using voice commands
- 🕐 Tell the current time and date
- 🎵 Play music from the Music folder
- 💻 Open Visual Studio Code
- 👋 Voice-based greetings and exit commands

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Wikipedia API
- Webbrowser
- Windows SAPI5
